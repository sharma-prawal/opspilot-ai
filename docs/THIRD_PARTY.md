## Data provenance

- `datasets/synthetic/knowledge/**` — runbooks, architecture notes, policies, error catalogue and postmortems for a
  fictional company ("Northwind Pay"), written for this repository. No real organisation, customer or system data.
- Telemetry, deployments and config changes are generated by `services/simulator` from a fixed seed (`1001`) and
  anchor time (`2026-11-03T14:00Z`).
- `datasets/evaluation/**` — questions, relevance labels and ground truth written by the project author alongside the
  corpus (not independently annotated; see caveats in `docs/evaluation/BASELINE.md`).
- IP addresses in synthetic logs use the documentation range `203.0.113.0/24` (RFC 5737).
