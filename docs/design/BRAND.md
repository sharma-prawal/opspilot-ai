# OpsPilot AI visual identity

The evidence-convergence mark joins three incoming paths at one open observation
lens. It represents investigation, not guaranteed causal proof. Original vector
studies and exports: apps/web/public/brand/. Use logo-light.svg on ivory/light
surfaces and logo-dark.svg on ink. Use symbol variants at 24 px or larger; keep
one quarter of the symbol width clear on every side. Do not stretch, rotate or
add glow. app-icon.svg is the square application source; favicon is exported from
the same mark. SVG wordmarks retain editable text (Georgia/system sans); the
symbol has no font dependency. PNG exports are provided for GitHub and docs.

Typography: Geist for controls and prose; Georgia for editorial headings; Geist
Mono for IDs, exact timestamps, measurements and code. Labels use sentence case.
Use 12–14 px for compact UI, 14 px for reading, and 28–36 px page headings.

Palette: ivory #fbfbf8, white #ffffff, warm stone #f4f3ec, ink #1c2529,
muted ink #626b74, burnt amber #ad4d1c, emerald #047857, rose #b91c1c.
Color carries a label: emerald = support/success, rose = contradiction/blocked,
amber = attention/selection. Dark logo exports use amber #eda36f for contrast. Unverified, unknown and not configured stay explicit.

Spacing: 4 px base, 8/12 px within a group, 20/24 px panel padding, 24/32 px
between sections. Fine 1 px rules, quiet flat panels, minimal shadows. Icons are
authored 28-unit vectors with a consistent 1.6-unit stroke; never use a provider
symbol to imply an implemented integration. Planned providers are labeled.

Motion: short color transitions only; reduced motion disables animated indicators.
Charts include units, values and textual alternatives. Avoid chart decoration,
fake time series and calibration claims.
