C0-F independent audit reproduction programs.

These are audit artifacts, not application changes. Run from the repository root with the existing .venv. The original four-case program is preserved separately in PHASE_C0_INDEPENDENT_REPRODUCERS.txt.

Programs 1 and 4 are pure/offline. Program 4 inspects protected ground truth only in the evaluation process; never send it through runtime tools or inference. Programs 2 and 3 WRITE ONLY audit-owned state to opspilot_test and verify exact SQL identity before writes. They do not run a model, an HTTP development workflow, or a remediation against opspilot. Program 2 leaves its workflow terminal and its KB document inactive; Program 3 leaves fresh simulator environments for audit, without creating investigations. Do not run alongside another test suite/E2E. Never change their database guards.

Copy each program between its BEGIN/END markers to a separate /private/tmp/<name>.py file. Execute from the repository root:
rtk proxy env PYTHONPATH=. PYTHONDONTWRITEBYTECODE=1 .venv/bin/python /private/tmp/<name>.py

import json
import os
from pathlib import Path
from opspilot_eval.agent_eval import load_truth, score_run
from uvicorn import Config

gt = load_truth("INC-003")
proposal = []
for pattern in gt["acceptable_plans"][0]:
    step = {"action_type": pattern["action_type"], **pattern.get("parameters", {})}
    if step["action_type"] == "rollback_deployment":
        step["service"] = "wrong-service"
    if step["action_type"] == "quarantine_messages":
        step["queue"] = "wrong-queue"
    proposal.append(step)
run = {"seconds_to_pause": 0, "seconds_total": 0, "status": "completed", "result": {"rca": {"remediation_plan": proposal}}}
scores = score_run(run, gt)
old = os.environ.get("WEB_CONCURRENCY")
os.environ["WEB_CONCURRENCY"] = "2"
try:
    workers = Config("opspilot_api.main:app").workers
finally:
    if old is None:
        os.environ.pop("WEB_CONCURRENCY", None)
    else:
        os.environ["WEB_CONCURRENCY"] = old
result = {"wrong_target_parameters": {"model_plan_acceptable": scores["model_plan_acceptable"], "executed_plan_acceptable": scores["plan_acceptable"], "actions_executed": len(scores["executed"])}, "inherited_web_concurrency_workers": workers}
Path("/private/tmp/opspilot_c0f_offline_boundaries.json").write_text(json.dumps(result, indent=2))
print(json.dumps(result, indent=2))
