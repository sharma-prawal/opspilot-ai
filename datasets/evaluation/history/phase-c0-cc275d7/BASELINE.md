## Caveats

- One author wrote the corpus, scenarios, ground truth and both question sets. The held-out set was written afterwards in operator phrasing and checked for 5-gram overlap with the corpus, prompts, tests and the development set (none found), but it is not independently annotated.
- Temperature 0 and a fixed seed make repeated trials near-deterministic: trials measure stability, not variance across model samples. Six scenarios is a small sample; rates are indicative.
- Several safety rules were added after observing failures on these same scenarios (see docs/DECISIONS.md D25-D28), so agent results on them are not an unbiased estimate of behaviour on unseen incidents.
